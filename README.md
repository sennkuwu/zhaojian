# 照见 · 中元夜网络纪念作品

> 一盏灯，也足以照见一个人。

《照见》是一个移动端优先的私密网络纪念仪式。无需注册，写一句话或什么都不写，持续按住三秒，给想念的人留一盏灯。

## 特性

- 默认私密：称呼、留言和灯只保存在当前浏览器
- 无字灯：不写任何内容也可以完成仪式
- 触摸、鼠标、键盘均支持三秒持续点灯
- 提前松手、失焦或切换标签页会自然取消，可重新尝试
- 点灯完成后，本地 CSS 孔明灯会缓慢升入夜色；默认约 10 秒，可随时跳过
- 静态纪念卡生成，默认不包含私人内容
- 支持减少动态效果和低性能设备
- 不依赖账号、声音、WebGL 或第三方分析服务

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run check
npm run build
```

## 隐私边界

这是 P0 私密模式版本。项目不会实现或展示公开留言、公共灯海、审核队列和服务端正文存储。私密内容不应被发送到服务器；清除浏览器站点数据后，私密内容无法恢复。

环境光和升空动画都是本地生成的抽象视觉，不代表其他参与者、公共灯海或参与数量。动画不上传称呼和留言。项目不提供通灵、祈福结果或逝者回应，也不模拟任何人的声音、肖像或文字。
